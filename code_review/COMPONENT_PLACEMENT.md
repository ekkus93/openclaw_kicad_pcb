## 1. Signal Flow Axis

- **Primary axis: left → right.** Inputs on the left, outputs on the right.
- Assign each component a **tier** based on its position in the signal graph (topological sort / longest-path layering).
- Place components at an x-coordinate proportional to their tier.

---

## 2. Component Tiers

| Tier | x-position | Typical contents |
|------|------------|-----------------|
| 0 | Leftmost | Signal sources, input connectors |
| 1 | | Input coupling/filtering (Cin, Rin) |
| 2 | | Gain stage (op-amp, transistor) |
| 3 | | Output filtering/coupling (Cout) |
| 4 | Rightmost | Load, output connectors |

Power supply components (decoupling caps, power connectors) are placed **above or below** the stage they serve — not in the main left-to-right flow column.

---

## 3. Vertical Grouping (Functional Clusters)

- Components that share more than one net belong in the same cluster and should be placed close together vertically.
- Metric: **shared net count / total net count** — sort by descending affinity within a tier.

---

## 4. Wire Routing Constraints

- Use only horizontal and vertical wires.
- Wires must not cross component bodies.
- Maximum wire length budget per net: **~30 mm** before switching to a label.
- Use **global or local labels** only when:
  - A wire would exceed the length budget, or
  - A net crosses more than one tier boundary.
- Otherwise prefer direct wires — avoid labels for nets that are local to a functional block.

---

## 5. Power and Ground Rails

- **VCC rail**: horizontal bus across the top of the sheet.
- **GND rail**: horizontal bus across the bottom of the sheet.
- Decoupling caps: placed between the rails, adjacent (same x-column, just above/below the IC they serve).
- Power pins (V+, V−) connect **vertically** to the rails and do not consume horizontal space in the main signal flow.
- Use global labels for VCC/GND only when the net spans more than one sheet.

---

## 6. Multi-Unit ICs

- Each unit is placed in the tier that matches its function (e.g. NE5532 unit A in the gain stage, unit B in the output stage).
- If the IC has a dedicated power unit, place it off the main flow, near the power rails.

---

## 7. Feedback Networks

- Feedback resistors/capacitors are drawn as a **U-bend**:
  - Wire comes off the output pin.
  - Runs above (or below) the amplifier.
  - Connects back to the inverting input.
- This keeps the main left-to-right signal flow unobstructed.
- Prefer routing above the amp unless ground connections make below more natural.

---

## 8. Symmetry for Stereo / Differential Designs

- Left channel: top half of the sheet.
- Right channel: bottom half of the sheet.
- Shared components (power supply, GND) centred between the two channels.

---

## 9. Layout Algorithm (Sugiyama-style)

1. **Build signal graph**: nodes = components, edges = shared nets.
2. **Assign layers (x-positions)**: longest-path layering assigns each node a tier.
3. **Order within layer (y-positions)**: minimise edge crossings using barycentric ordering.
4. **Route wires**: short/local nets → direct wire; long or cross-layer nets → label.

---

## 10. Component Orientation

### Core Rule: Align Pins with the Wire They Connect To

Orient each component so its pins point **along the wire** that carries its signal — no unnecessary bends at the pin.

### Orientation by Component Role

| Role | Orientation | Reasoning |
|------|-------------|-----------|
| Series passive (coupling cap, series R in signal path) | **0° (horizontal)** | Sits on a horizontal signal wire; pins point left and right |
| Shunt passive (bypass/decoupling cap, pull-up/pull-down R) | **90° (vertical)** | Bridges between a horizontal net and VCC/GND rail above/below; pins point up and down |
| Op-amp / IC | **0°** | Inputs on left, output on right; follows signal flow axis |
| Left-side connector | **0°** | Pins point right, toward the circuit |
| Right-side connector | **180°** | Pins point left, toward the circuit |
| Potentiometer | **90°** | Three terminals connect vertically between signal and ground rails |
| Power symbol (VCC) | 0° (vertical by definition) | Always points up |
| GND symbol | 0° (vertical by definition) | Always points down |

### Decision Algorithm

```
For each component:
  If it is in the main signal path (series between two signal nodes):
    → 0° (horizontal)
  Else if it connects between a signal net and a power/ground rail:
    → 90° (vertical)
  Else if it is a connector:
    → 0° if on the left edge, 180° if on the right edge
  Else if it is an IC:
    → 0° (never rotate ICs unless mirroring for a second channel)
```

### Practical Examples (Headphone Amp)

| Component | Orientation | Reason |
|-----------|-------------|--------|
| C_in (input coupling cap) | 0° | Series in signal path |
| C_bypass (decoupling cap on V+/V−) | 90° | Shunt to power rail |
| R_feedback | 0° | Horizontal wire from output back to inverting input |
| R_gain / R_load (shunt to GND) | 90° | Bridges signal net to GND |
| Volume pot (RV1) | 90° | Wiper to signal, ends to GND and input |
| NE5532 | 0° | Inputs on left, output on right; never rotate |
